# Development Workflow

## Before Work

- Load Hermes runtime and core memory.
- Create or update a ticket.
- Identify relevant feature, workflow, convention, or ADR docs.

## During Work

- Make scoped changes.
- Preserve established architecture.
- Record meaningful discoveries in the ticket.

## After Work

- Run verification.
- Update related memory.
- Update `current-state.md` when project status changes.
- Close the ticket only after verification and memory updates.
