# Debugging Workflow

## Process

1. Observe the symptom.
2. Reproduce or inspect evidence.
3. Trace to the failing path.
4. Identify root cause.
5. Fix the smallest responsible cause.
6. Verify the fix.
7. Record the bug memory.

## Required Memory

Bug fixes require a `hermes/memory/bugs/BUG-XXX-*.md` document unless the issue is purely external or explicitly out of scope.
