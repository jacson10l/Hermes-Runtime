# Hermes Runtime

This directory contains the project-local Hermes Runtime instance.

Hermes Runtime turns engineering work into recoverable AI context. It is optimized for:

- summary-first context loading
- task-level documentation closure
- retrieval-based project memory
- minimal, traceable code changes
- long-term AI collaboration

## Completion Rule

A task is incomplete unless the relevant Hermes memory has been reviewed and updated.

Code changes without task, memory, or verification records are not complete.
